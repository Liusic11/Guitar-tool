# 吉他指板训练器（Guitar Fretboard Trainer）

一个纯前端、可交互的吉他指板音记忆练习器。拟真 SVG 指板 + Web Audio 实时合成拨弦音色，
**无需任何音频文件、无需后端、无需联网**。

支持三种练习模式与间隔重复（SRS）智能抽题：

| 模式 | 说明 |
| --- | --- |
| 找位置（find） | 给定「弦-音名」（如 6-C），在指板上找出对应品位 |
| 认音名（name） | 指板高亮某位置，你说出它是什么音 |
| 找八度（octave） | 高亮一个位置，在其他弦上找出所有同名八度 |

两种节奏：**自动模式**（1–5s 倒计时后自动揭示）与 **手动模式**（按钮揭示 / 点指板作答）。
设置面板可调调弦、品数范围、音名/唱名体系、音量，以及查看「记忆强度」热力图。

## 一、在另一台电脑上把它跑起来

### 1. 把项目带过去
直接复制整个项目文件夹即可。复制时**跳过**以下三个目录（它们都能重新生成，且 `node_modules` 体积约 120MB）：

- `node_modules/`（依赖，install 时重建）
- `dist/`（构建产物）
- `.shots/`（本地截图，无关紧要）

> 推荐做法：用 U 盘 / 移动硬盘 / 网盘拷文件夹，或提交到 Git 后 `git clone`。
> 项目已包含 `.gitignore`，`node_modules`、`dist` 不会被提交。

### 2. 安装 Node.js（新电脑只需做一次）
去 https://nodejs.org 下载 **LTS** 版本安装。要求 Node 18 及以上（Node 22 也完全兼容）。
安装后打开终端验证：
```bash
node -v
# 显示 v18.x / v20.x / v22.x 等即正常
```

### 3. 安装依赖并启动
在**项目文件夹内**打开终端，执行：
```bash
npm install      # 安装依赖（依据 package-lock.json 锁定版本）
npm run dev      # 启动开发服务器
```
启动后浏览器会自动打开 `http://localhost:5173/`。
如果没自动打开，手动访问这个地址即可。

## 四、关于练习进度（重要）

SRS 记忆强度与统计数据保存在**浏览器 `localStorage`** 中，按域名隔离。
因此换电脑、换浏览器后，新机器上是**全新的记忆库**——这正好用来检验你是否真的记牢了。

> 如果你希望两台电脑的练习进度能同步，可以加一个「导出 / 导入记忆库」（JSON 文件）的功能。

## 五、项目结构

```
src/
  lib/
    music.ts        # 音乐理论：调弦、MIDI、音名/唱名、题型与加权抽题
    srs.ts          # 间隔重复记忆模型
    audio.ts        # Web Audio 拨弦音色合成引擎（Karplus-Strong）
  hooks/
    useQuizEngine.ts # 练习状态机（三模式 + 统计 + 持久化）
  components/
    Fretboard.tsx   # 拟真 SVG 指板（玫瑰木纹理、金属品丝、高亮/拨弦动画）
    PromptStage.tsx # 出题区（音名键盘 / 八度标记进度）
    CountdownRing.tsx # 自动模式倒计时环
    SettingsDrawer.tsx # 设置面板（含记忆强度热力图）
  App.tsx           # 页面装配与交互编排
  index.css         # 设计系统（复古制琴工坊主题）
```

## 六、常见问题

**Q：`npm install` 很慢或报错？**
A：检查 Node 版本（需 18+）。国内可换源：`npm config set registry https://registry.npmmirror.com`。

**Q：打开是空白页？**
A：确认终端里 `npm run dev` 没有红色报错；访问的是 `http://localhost:5173/` 而非文件直接双击 `index.html`。

**Q：没有声音？**
A：浏览器要求用户先交互才允许播放音频，先点一下页面任意位置（或按空格开始）即可。也检查右下角音量是否调为 0 或静音。

**Q：想改调弦 / 品位范围？**
A：点右上角「设置」图标，在面板里调整，实时生效。
