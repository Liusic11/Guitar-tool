## 本次修改：双栏布局统一断点 + 1080p 一页铺满不滚动

用户反馈：两张开发屏截图（2240×1400 / 2560×1440）上同一页面看起来不同；要求以**练琴屏 1920×1080（16:9 1K）** 为准，和弦页与音阶页都要「一页铺满、不上下翻」。

根因：页面是响应式布局，按浏览器窗口有效宽度切换——副屏窗口更窄（且 Windows 缩放比更高会把有效宽度压更窄），于是双栏被挤窄甚至变单栏，外观不一致。开发屏不重要，目标锁定 1080p。

修改内容（`src/index.css`）：
- 统一断点：`.scale-layout` 单栏阈值 1200px → **1024px**；`.chord-layout` 860px → **1024px**。这样 1920×1080 全宽必然走双栏，两块屏表现一致。
- `.scale-layout` / `.chord-layout`：`align-items` 由 `start` 改 **stretch** + `min-height: 0`，让左右两栏等高、撑满一页高度。
- `.chord-figure` 改为 flex column；`.chord-actions` 加 `margin-top: auto` + 顶部内边距，沉到卡片底部填补空白。
- `.scale-theory` 改为 flex column；`.scale-demo`（演示按钮）加 `margin-top: auto`，沉到乐理卡底部，整页不再空一截。

验证：`tsc --noEmit` 通过；`vite build` 通过（47 模块）；开发服务器重启在 `localhost:5173`。

用户设备事实：开发电脑 2240×1400 + 2560×1440（不用于练琴）；练琴屏 1920×1080 / 16:9。布局以此屏为基准优化。

## 本次修改：音阶页「铺满一页」垂直 flex 链修复
用户反馈：上一轮把 `.fretboard-scroll` 的 `min-height` 拿掉后，左栏塌短、底部出现空白，页面又没铺满一屏。
根因：指板 SVG viewBox 1640×226（约 7.25:1 宽条），宽度被左栏限制后高度恒为 ~150px，无法自己撑满；而 `.scale-figure`/`module-scroll` 没有形成「flex 撑满视口高度」的链，导致两栏高度 < 视口高、底部留白。
修改（`src/index.css`）：
- `.module-scroll` 改为 `display:flex; flex-direction:column`；`.chord-panel`/`.scale-panel` 加 `flex:1 1 auto; min-height:0; display:flex; flex-direction:column`。
- `.scale-layout`、`.chord-layout` 加 `flex:1 1 auto; min-height:0`，使网格撑满面板高度。
- `.scale-figure .fretboard-scroll` 改 `flex:1 1 auto; min-height:200px; align-items:center; justify-content:center`；`.fretboard` 加 `min-height:200px; max-height:280px`。左栏指板区吸掉多余纵向空间，两栏都顶到一屏底，无底部空洞。
- 右栏 `.scale-theory` 已有 `display:flex; flex-direction:column` + 演示按钮 `margin-top:auto` 沉底，跟齐左栏高度。
验证：`tsc` 通过；`vite build` 通过（47 模块）；dev server 重启 `localhost:5173`（task Nx9O46）。
说明：指板本身是宽条，1080p 下视觉高度约 150px（受宽度限制），其余纵向由组成音卡 + 形状卡 + 右栏乐理/老师提示填满，整体无滚动、无底部空白即视为「铺满一页」。
